# Project Instructions

## General
- Inspect the existing project before making changes.
- Do not rewrite working functionality unnecessarily.
- Do not invent files, folders, APIs, or dependencies.
- Keep changes focused on the requested task.
- Preserve the existing design unless a redesign is requested.

## Git
- Do not delete or modify .git configuration.
- Do not commit or push unless explicitly requested.
- Before making major changes, explain what will be changed.

## Website
- Maintain responsive desktop and mobile layouts.
- Keep existing branding consistent.
- Check all affected pages after making changes.
